# MVP Planning Workflow

Analyze the approved Requirement Analysis.

Your goal is to identify the smallest product scope required to validate the main user value.

## Process

1. Identify the primary user goal.
2. Identify the core user journey.
3. Identify features required for the journey to work.
4. Identify features that can be postponed.
5. Identify dependencies.
6. Identify risks.

## Feature Classification

Classify each feature as:

- Must Have
- Should Have
- Could Have
- Out of Scope

## MVP Rules

The MVP must:

- Solve one clear user problem.
- Have a complete core user journey.
- Avoid unnecessary features.
- Minimize the number of screens.
- Avoid complex edge cases unless critical.

## Output
